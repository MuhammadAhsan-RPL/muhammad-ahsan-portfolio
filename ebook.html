E‑Book Platform

Full‑stack Academic Laravel

Overview

A digital library platform that allows users to browse, borrow, and read books online. Built with secure authentication, book cataloging, and a responsive reading interface. This academic project demonstrates full-stack capabilities with Laravel.

The Problem

Schools lacked a centralized digital library system. Students couldn't easily access books remotely, and librarians struggled to track borrowing history.

The Solution

A full-stack web application with user roles (admin, librarian, student), book borrowing system, and digital reading interface. Admin can manage books, track loans, and generate reports.

Key Features

  • User authentication (Admin, Librarian, Student)
  • Book catalog management
  • Borrowing & return system
  • Digital book viewer
  • Borrowing history & reports

Tech Stack

Laravel 10 PHP 8.2 MySQL Tailwind CSS Alpine.js
