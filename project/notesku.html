Project Overview

Notesku is a modern note-taking web application engineered independently to practice authenticated CRUD workflows, user data isolation, and non-destructive archiving in Laravel and MySQL.

The Challenge

Active workspaces quickly become cluttered when old notes mix with current tasks, yet deleting notes permanently risks losing valuable information. Users needed a fast, private environment with clean lifecycle states.

The Solution

I designed an authenticated multi-tenant workspace where each user owns an isolated note collection—complete with instant keyword filtering, one-click archiving, state restoration, and responsive mobile ergonomics.

Key Application Features

Private Authenticated Workspaces

Strict ownership policies ensuring users can only view, edit, or manage their own notes.

Fast Note Creation & Editing

Streamlined editor interface designed for capturing thoughts and daily tasks without friction.

Archive & Restore Lifecycle

Move completed notes out of the primary view and restore them anytime with a single click.

Search, Filter & Responsive UI

Quickly locate notes by title or content across desktop and mobile viewports.

Project Retrospective & Learnings

What I Learned

What began as a straightforward note-taking app evolved into a practical study in authorization policies, query scoping, and state management. Implementing archive and restore states alongside user-scoped queries reinforced how thoughtful backend design directly translates into a cleaner, safer user experience.
